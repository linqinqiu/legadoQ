# 端口与用户配置复查（2026-11-17）

## 0. 结论先说

1. **改端口不会碰用户的配置**：界面偏好存在服务端（数据目录里的 `ui-prefs.json`），不是靠浏览器 localStorage 活着的；
   实测 12346 → 12347 换端口起服务，偏好原样读回（见 §1）。
2. 复查中发现**两个真问题**，都在桌面壳「记住端口」这条路上（§2）：一个会把启动打断，一个会让用户改了 `.env` 却静默不生效。
3. 顺手抓到**三份文档里的端点数停在 165**（契约已经 166），并把这个漂移放进了 `docs:api-check` 门禁（§3），
   负向测试验过：改回 165 立刻红，报出 `文件:行号`。

## 1. 实测：换端口之后配置还在

```bash
# 12346 上改一项偏好
curl -X PUT -H 'Origin: http://127.0.0.1:12346' -H 'Content-Type: application/json' \
     --data '{"kind":"none","palette":"violet"}' http://127.0.0.1:12346/api/ui-prefs/wallpaper   # 204
node stop.mjs && LEGADO_DATA_DIR=... node start.mjs --port 12347 --no-open
curl http://127.0.0.1:12347/api/ui-prefs
# → {"prefs":{"wallpaper":{"kind":"none","palette":"violet"}}}
```

落盘位置：`<数据目录>/ui-prefs.json`（与库同级，跟着数据目录走）。浏览器侧由 `lib/uiPrefs.ts` 在 React 渲染前
把缺的键补回 localStorage —— 补写发生在渲染前，所以不会出现「先按默认画一帧再跳成用户设置」的闪动。

## 2. 修掉的两个问题（都在 `DesktopLauncher.kt`）

### 2.1 `port.txt` 写不进只读目录时，整个启动被打断

端口被别的程序占用时会顺延，并把新端口写回 `port.txt` 记住。数据目录有 `chooseDataDir` 兜底（装进
`C:\Program Files` 时退回 `%LOCALAPPDATA%`），**但这行 `writeText` 没有**：安装目录只读时抛 IOException，
直接打断 main —— 用户看到的是「双击没反应」，而不是「起在 1235 上，只是没记住」。

改成 `runCatching`：写失败照常起在空闲端口上，日志说明「这个端口没记住」；下次再顺延一遍，代价只是启动时多探几个端口。

### 2.2 `.env` 里改的端口被 `port.txt` 静默盖掉

端口优先级是 `port.txt` > `.env`/环境变量 > 1234。这个顺序本身是对的（界面里改的端口不该被旧 `.env` 盖回去），
**但两者不一致时一句话都不说**：用户明明改了 `.env`，重启后端口没变，日志只有一句「启动中 http://…:旧端口」，猜不出原因。

现在会在启动日志里明说：`.env` 的 `LEGADO_PORT=X` 没生效、实际用 `port.txt` 的 Y、要生效就先删 `port.txt`。
（不改优先级：改了会让「界面里改端口」下次被 `.env` 盖回去，那是更糟的方向。）

## 3. 文档端点数漂移 → 新增门禁

`docs/API-REFERENCE.md` 是脚本生成的，所以永远准；但 `ARCHITECTURE.md` / `STATUS.md` / `ROADMAP.md` 是手写的，
里面各有一到三处「165 条端点 / 19 组」。加完 `GET /api/backup/export` 之后没人回头改，三份文档就一起停在了 165。

修数字只是打补丁，所以把判据放进了 `product/scripts/gen-api-reference.mjs --check`（即 `npm run docs:api-check`）：
扫 `docs/` 下五份手写文档里「端点数：N」「N 条端点」「N 条 / M 组」「当前返回 N 条」「端点分布（N 条」这几种写法，
与契约比；不一致就报 `文件:行号` 并退出 1。口径刻意收窄——「AI 22 个端点」这类分组内数字不算在内。

负向测试（2026-11-17）：把 `STATUS.md` 的 166 改回 165 → 门禁红并指出 `STATUS.md:52`；改回来 → 绿。

## 4. 按设计「不跨端口」的东西（不是 bug，别当 bug 修）

- **壁纸图片本体**在 IndexedDB，按 origin 隔离；换端口只有「设置」过去了，图得重新上传一次（`lib/wallpaper.ts` 的注释里写明）。
- **AI 悬浮球位置 / 隐藏状态、AI 对话与工具分组、离线快照**：`lib/uiPrefs.ts` 的收录口径里明确排除（临时/设备态，或属于 AI 模块单独演进）。
