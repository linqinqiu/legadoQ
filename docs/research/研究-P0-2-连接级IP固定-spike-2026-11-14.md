# P0-2 spike：连接级 IP 固定（本地回环 CONNECT 代理）

> 日期：2026-11-14 ｜ 仓库：`E:\legado` ｜ 分支 `main` ｜ 起点 `a95fd8f`
> 性质：**spike**。不改生产代码，结论用于决定 P0-2 是否按方案 A 落地。
> 对应：`docs/engineering/audit/PHASE2_PREFLIGHT_REPORT.md` §3.2 / §6.3。

## 0. 结论（先看这里）

**方案 A 可行，且是本仓库唯一不需要重写网络层的做法。** 但有两条实测发现必须先纠正方案里的假设：

1. **不是只有 CONNECT。** JDK 17 的 `HttpClient` 对 `https://` 发 `CONNECT host:port`（盲隧道），
   对 `http://` 直接向代理发**绝对形式请求行**（`GET http://host/path HTTP/1.1`）。
   只写 CONNECT 隧道的话，所有明文 http 书源都会 405 —— 书源库里明文 http 站点并不少。
2. **TLS 与 SNI 不需要特殊处理。** CONNECT 之后是盲字节转发，TLS 握手、证书校验、SNI、
   ALPN 全在客户端与源站之间完成，代理不参与，也不会看到明文。

## 1. 实测方法与结果

PoC 是 4 个临时 JUnit 用例（跑完即删，代码见 §5）：一个只收报文的假代理、一个回声音箱、
一个最小 CONNECT 隧道代理（可注入解析器）。命令：

```
cd product && ./gradlew :app:test --tests "io.legado.PinnedProxySpikeTest"
```

| 用例 | 实测输出 | 结论 |
| --- | --- | --- |
| `https://` 走代理 | `CONNECT spike.example:443 HTTP/1.1` | 隧道模式；代理拿到的是 `host:port`，**此时还没解析 DNS** |
| `http://` 走代理 | `GET http://127.0.0.1:9/probe?x=1 HTTP/1.1` | 绝对形式；代理必须自己解析请求行、改写为 origin-form 再转发 |
| CONNECT 隧道字节透传 | 3 个分块分别立即回声 | 不做整包缓冲 → SSE / 媒体流可用 |
| CONNECT 到私网（解析返回 `10.1.2.3`） | `HTTP/1.1 403 Forbidden`，无建连 | 解析 → 校验 → 拒绝发生在 connect 之前 |

4 项全绿（`TEST-io.legado.PinnedProxySpikeTest.xml`，`tests="4" failures="0"`）。

**为什么这就堵住了 TOCTOU**：代理是**唯一**建立 TCP 连接的地方。它解析一次域名，对**同一批
`InetAddress`** 做校验，然后连**那个** `InetAddress`。JDK 的 `HttpClient` 只跟代理（127.0.0.1）
建连，不再自己解析目标域名 —— 校验过的地址与实际连接的地址是同一次解析的结果。

## 2. 落地设计（如果做）

新增 `ops/PinnedProxy.kt`（约 200-250 行），职责单一：

```
PinnedProxy(resolver: (String) -> Array<InetAddress>, allowLoopback: Boolean)
  start()  // 绑 127.0.0.1:0，端口由系统分配
  port     // 交给 ProxySelector.of(InetSocketAddress(loopback, port))
  close()  // 随进程/服务关闭；幂等
```

- **HTTPS**：读 `CONNECT host:port` → `resolver(host)` → `NetworkSecurity.validateResolvedAddresses`
  → `Socket(addresses.first(), port)` → 回 `200 Connection Established` → 双向 `copyTo`。
- **HTTP**：读请求行（绝对形式）→ 解析出目标 URI → 同样解析+校验 → 连固定 IP →
  把请求行改写为 origin-form，`Host` 头补全，其余头与 body 原样流式转发（不缓冲整包）。
- **接线点**：`NetworkSecurity.newHttpClient` 里 `.proxy(ProxySelector.of(...))`，`GuardedHttpClient.guard()`
  保持不动（两道检查叠加，不互相依赖）。代理单例随进程启动，懒初始化。
- **`allowLoopback`**：本机模型（Ollama / LM Studio）必须放行 127.0.0.1/::1，与现有开关同源；
  代理要能按请求判断，不能用全局布尔（同一进程里书源出站仍须拒回环）。实现上按「代理实例」区分：
  `NetworkSecurity` 维护两个代理实例（严格 / 放行回环），client 工厂按参数选。

## 3. 必须处理的坑（按风险排序）

| # | 坑 | 处理 |
| --- | --- | --- |
| 1 | 明文 http 走绝对形式，不是 CONNECT | 代理必须实现两种模式；先做 CONNECT-only 会让 http 书源全挂 |
| 2 | 代理自身必须只绑回环 | `ServerSocket(0, backlog, InetAddress.getLoopbackAddress())`；绑 0.0.0.0 等于给局域网开正向代理 |
| 3 | 请求取消 / 超时传播 | 客户端断连要能中断隧道线程；否则线程泄漏。用 `copyTo` + `soTimeout`，并在 `finally` 关两端 |
| 4 | 重定向 | 现状 `Redirect.NEVER`，每条请求独立过代理，不需要特判；若将来打开跟随，跳转目标同样经代理 |
| 5 | 端口耗尽 / 并发 | 每条 CONNECT 两个线程（上行 + 下行），用虚拟线程或小线程池；不加池会在大章批量抓取时线程暴涨 |
| 6 | HTTP/2 | 隧道内 ALPN 由客户端与源站协商，代理盲转发；不需要 h2 支持，但**不能**在隧道里做任何字节改写 |
| 7 | 代理解析缓存 | 复用 `NetworkSecurity` 现有 5 分钟 DNS 缓存口径，避免每个请求都解析一次 |
| 8 | 本机服务自己 | 现有「拒指向自己」判定在 `ServerIdentity`，代理不重复实现；但代理放行回环时更要保证这条判定仍在 |

## 4. 建议

1. **做**，按 §2 一次实现两种模式（只做 CONNECT 会让 http 书源回归，属于不可接受的半成品）。
2. 先落 `PinnedProxy` + `PinnedProxyTest`（6 项：CONNECT 成功、http 绝对形式转发、私网拒绝、
   解析只发生一次、SSE 不缓冲、TLS 主机名校验仍生效），再接 `newHttpClient`。
3. `PinnedProxyTest` 里「解析只发生一次」用注入解析器计数断言；TLS 那项需要本地自签证书，
   若搭起来成本高，就退化为「隧道字节透传 + 证书校验由 JDK 负责」的说明性判据，并标注
   `NEEDS_RUNTIME_TEST`（真实外网 HTTPS + SSE 手测一次）。
4. 不做运行时开关：安全边界不能被配置关掉（与 `PHASE2_PREFLIGHT_REPORT.md` §6.3 一致）。

## 5. PoC 关键代码（临时文件已删）

```kotlin
// 最小 CONNECT 隧道：解析一次 → 校验 → 连同一个 InetAddress → 双向盲转发
private fun handle(client: Socket) = client.use {
    val head = readHead(client.getInputStream())
    val authority = head.lineSequence().first().removePrefix("CONNECT ").substringBefore(" HTTP/")
    val host = authority.substringBeforeLast(':')
    val port = authority.substringAfterLast(':').toIntOrNull() ?: 443
    val addresses = resolve(host)                     // 注入的解析器，测试里用来数次数
    if (addresses.isEmpty() || addresses.any { blocked(it, allowLoopback) }) {
        client.getOutputStream().write("HTTP/1.1 403 Forbidden\r\n\r\n".toByteArray())
        return@use
    }
    val origin = Socket(addresses.first(), port)      // 连的就是校验过的那一个
    origin.use {
        client.getOutputStream().write("HTTP/1.1 200 Connection Established\r\n\r\n".toByteArray())
        client.getOutputStream().flush()
        val up = thread(isDaemon = true) { client.getInputStream().copyTo(origin.getOutputStream()) }
        origin.getInputStream().copyTo(client.getOutputStream())
        up.join(2000)
    }
}
```
