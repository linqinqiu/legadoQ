> 用户可见变化看 [`product/CHANGELOG.md`](../../product/CHANGELOG.md)，逐轮工程记录看 [`../sessions/`](../sessions/)。

## 写法约定

- 一份文档只回答「当时查到了什么、决定怎么做、判据是什么」，不复制会变的测试数、端点数和版本号。
- 结论变了就新开一份 `研究-<新主题>.md`，并在开头注明承接哪一份；不回头改旧快照。
- 路径引用一律写仓库根相对路径（如 `product/docs/restructure/facts.md`），避免移动目录后整篇失效。
