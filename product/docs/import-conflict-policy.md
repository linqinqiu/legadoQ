# 导入冲突策略

`enabled` / `isEnabled` 是本机运行状态，不属于各类定义字段。当前各入口有意保留不同策略；修改入口或冲突语句时，必须同步更新本矩阵和 `ImportConflictPolicyTest`。

| 对象与入口 | 已存在记录冲突时的本机开关策略 | 新记录 |
| --- | --- | --- |
| 普通书源保存（`saveSource`） | 按请求覆盖 `enabled` | 按请求值 |
| 书源备份导入（`importSources`） | 保留本机 `enabled` | 使用备份值 |
| RSS 源导入（`importRssSources`） | 使用导入值覆盖 `enabled` | 使用导入值 |
| 替换规则导入（`importReplaceRules`） | 使用导入值覆盖 `isEnabled` | 使用导入值 |
| 书源订阅保存（`saveSubscription`，按 URL 冲突） | 使用请求值覆盖 `enabled` | 使用请求值 |

备份导入保护本机书源开关，是为了避免恢复另一设备上的完整书源包时批量改变本机策展。RSS、替换规则和订阅入口采用定义整体覆盖语义，开关随导入定义一同更新。普通书源保存是显式保存操作，提交值总是生效。

这是一份行为规范，不代表不同领域必须统一成同一种策略。若产品将来决定改变其中一项，须作为有意识的数据行为变更处理。

## 书源标识与包内版本合并

当前 `SourceCodec` 会去除 URL 的 `#` / `##` 注解，再以归一化后的标识入库；同标识取包内最后一条。原始 URL 各不相同，也可能在本机合并，不能将这类记录直接判成可删除的重复书源。预览在确认前提示有效书源数、归一化标识数与合并数量；此提示没有改变既有标识协议。

真实样本中 7,441 条书源变成 5,571 个本机标识，合并 1,870 个版本。运行库仍采用此身份规则；已有书架、登录态、缓存和删除记录不改键，不把合并版本判成可安全删除的重复项。

勾选书源且存在同标识冲突时，确认流程强制生成 `source-variants-<内容SHA256>.json`，在「收下的文件」列表单独下载，不受「个性化条目」勾选控制。留档格式为 `legadoq-source-variants-v1`：`backupSha256` 绑定输入文件，`bookSource` 保存全部原始书源对象及顺序，`bookshelf` 保存全部原始书架对象（包括未选择导入的书架）；`conflicts` 用零基索引记录同标识版本与最后胜出的条目。旧格式字段、扩展字段和原始 `origin` 保留 JSON 值，不承诺字节/缩进与原文件相同。原始书源定义可能包含请求头或凭据，下载件应与原备份同样私密保管。

预览不写留档，并说明书架仍关联归一化后的胜出版本，原始关联可能有歧义；留档不是自动修复关联或注册全部可执行版本。相同输入与内容复用同一个文件；不同备份按内容另存，已有文件校验不符时不覆盖。缺少留档目录或写入/校验失败时，数据库全部域回滚，HTTP 返回 `500 backup_archive_failed`，响应不暴露本机路径。普通个性化文件仍在数据库提交后保存，不是库与文件的跨存储原子事务。如果留档完成后 SQLite 最终提交失败，可能留下恢复证据；其存在不表示导入成功，不自动删除历史证据。

`all` 仍只导出六个原生域，不包含冲突留档；迁移机器可使用下面的显式迁移包，仍建议保留原始 ZIP。历史版本仅经下面的独立预览和确认流程启用，不证明全部版本可同时执行、无损迁移或手机恢复兼容。

## 历史书源版本启用（2026-11-28 工作树）

「收下的文件」中合法的版本留档提供「查看版本」：按规范 ID 分组，每页 20 组，支持名称/ID 筛选。三个同源 POST `/api/backup/source-versions/list`、`preview`、`activate` 分别负责查询、只读预览和显式确认。每次读取先验证精确文件名、内容 SHA-256 和冲突索引；不把留档直接注册为可执行书源库。

启用沿用原来的规范 ID，**全局替换该 ID 的规则，影响全部关联书籍**，不创建带版本的新 ID。保留本机启停和排序、正文/净化/目录缓存及该规范 ID 的登录/脚本状态；旧缓存可能继续显示旧结果，不自动重抓。旧体检记录和健康标签清除，需重新体检。预览列出影响数量、最多 20 本书名、缓存条数及这些边界。

原始书架 `origin` 只有同时满足「属于此冲突组的原始别名、规范化到同一 ID、留档中有精确 bookUrl、本机仍有该书」才成为关联候选，默认不勾选。显式勾选后原地改归属，保留书架元数据/分组、进度、笔记、日志和缓存；只按精确书籍 URL 与目录 URL 复制目录缓存，保留旧别名目录副本。同别名共享目录只复制一次；不同别名争用同一目标目录键、多个别名指向同一目标书、目标已有任何相关行或删除墓碑时拒绝，不静默覆盖。别名整源登录/脚本状态不迁移；所选规则本身仍可能包含脚本、请求头和内嵌凭据，只启用可信版本。

预览不写数据库或快照。确认绑定留档、原始版本索引、勾选项和相关本机行；源、书架、进度或相关记录变化时返回 `409 source_version_changed`，需重新预览。相关后台缓存任务未退出或数据库仍标记缓存中时返回 `409 source_version_busy`。确认在单写锁内强制制作并校验完整 SQLite 快照，失败拒绝写入；规则替换与书籍关联共用事务，中途失败整笔回滚，原留档始终保留。

成功响应显示安全快照名。恢复要在「启动快照」排定该快照并重启，属于**全库回滚**，启用之后的其他新改动也会回退，并非单书撤销。快照位于本机数据目录，版本启用不借机清理旧恢复点。此流程不自动应用留档设置，不联网重抓，也不改变手机备份或 WebDAV 同步协议。

## 含留档的迁移包（2026-11-27 工作树）

备份页「导出含留档的迁移包」调用 `GET /api/backup/export?domain=recovery`。ZIP 根目录是六个原生域与 `legadoq-migration.json`，已收下的个性化文件和内容寻址书源证据位于 `kept/<原文件名>`。清单 `format=legadoq-migration-v1`，`files` 记录各留档的 `name`、实际 `bytes`、`sha256`。`kept/sourceSub.json` 是原始订阅留档，根 `sourceSub.json` 是本机原生订阅，两者不会混用，即使条目顺序被调整。

导入和预览在任何写入前检查精确路径、缺项、重复路径、留档大小写别名、清单版本、实际字节数与留档 SHA-256；书源证据另校验内容寻址文件名及冲突索引。清单实际不超过 1 MiB，最多 1,024 个留档，每条目最多 64 MiB、总展开最多 256 MiB；导出完成并检查压缩包不超过 64 MiB 后才发送成功响应。格式问题返回 `400 invalid_backup`，导出校验、目录或容量失败返回安全的 `500 backup_export_failed`。哈希用于损坏检查，不是来源认证，仍只应导入可信文件。

恢复继续按模块确认：源版本证据随「个性化条目与恢复留档」选择，原始订阅文件随「书源订阅」选择；不自动激活证据里的版本或应用设置。证据写入失败回滚原生域；普通个性化文件沿用提交后保存语义，不承诺 SQLite 与文件跨存储原子性。迁移包可能含私密配置/原始请求头，应按原备份保密。

这是六域和已留档文件的迁移格式，不是 Android 原始整包、完整 SQLite 快照或同一时刻的全域一致快照，不包含封面、本地书文件、缓存、独立登录态等未导出数据。导出读取的留档原始字节合计最多 256 MiB；校验还会生成字符串与解析对象，实际峰值内存更高，超大留档应分别下载。手机 App 恢复仍需另验。

## 手动 WebDAV 传输边界（2026-11-28 工作树）

备份页支持公网 HTTPS WebDAV 的列目录、上传迁移包与拉取。目录须预先创建，仅识别本产品含时间、随机标识和 SHA-256 的迁移文件名。上传使用唯一名及 `If-None-Match:*`，PUT 成功后再 GET 回读校验实际大小和哈希；未通过校验不报告备份成功。失败可能已留有远端文件，不自动删除或覆盖。拉取验证哈希后返回 ZIP，不写数据库或留档；页面复用现有预览、策略选择和确认接口。

凭据只在当前页面内存与当次请求使用，不写入配置或持久存储，不跟随重定向；生产复用严格出站客户端，暂不支持本机或 NAS 私网直连。拒绝 URL 内嵌凭据、查询、片段和目录穿越。PROPFIND 使用 Depth:1，最多 2 MiB XML / 2,000 条响应，禁用 DTD 与外部实体，远端 href 不作为请求地址；单包传输最多 64 MiB，响应体读取也有 60 秒截止。

此功能是手动迁移，不是连续双向同步；没有定义离线编辑、删除和多设备冲突合并协议。迁移包含私密留档时须自行保护远端权限；文件名哈希只能检测传输损坏，不能证明来源可信。自动化验收使用隔离 HTTP 模拟服务与显式测试客户端；浏览器模拟远端响应后调用真实预览，不等于真实公网供应商账号验收。

## 书架与进度的显式恢复策略（2026-11-27 工作树）

新界面先预览、再确认；`libraryPolicy` 将元数据和进度分开选择，不能拿进度时间冒充元数据修改时间。

| 字段 | 值 | 含义 |
| --- | --- | --- |
| metadata | `keep_local`（默认） | 已存在书的名称、作者、目录、封面、完结状态保留；新书新增 |
| metadata | `overwrite` | 采用包内信息，空封面不抹掉本机封面；已有书仍保留本机分组 |
| progress | `newer`（默认） | 仅采用有效正时间且严格晚于本机的进度；相同时间保留本机；缺时间跳过，包括本机尚无进度的情况 |
| progress | `overwrite` | 采用明确携带的进度，允许回退；缺时间按本次导入时间保存 |
| progress | `keep_local` | 不恢复任何进度，也不为新书生成进度 |

明确携带 `durChapterIndex=0` 是有效首章；没有该字段不凭空生成进度。采用备份进度时清除旧段落锚点、内容校验值并重置定位版本；书架最近阅读时间不向后回退。包内同一本书的重复项取最后一条，单独报告重复数。所有策略均尊重删除墓碑，不复活已删书。

预览用只读快照计算 `libraryDiff`，只预测书架与进度；更新数量表示策略选择处理的已有记录，不逐字段判断内容是否相同。其余模块仍展示包内可解析数量。确认须带 `libraryPolicy` 与 `previewToken`：凭证绑定文件和策略，以及包内相关书的书架、进度、墓碑完整行；在任何域写入前、同一写事务内重新计算。选中书架且相关行变化时返回 `409 backup_preview_changed`，不写书源、凭据或留档，要求重新预览。未选书架则不因本机书架变化阻断其他模块，但仍校验文件与策略。凭证用于变化检查，不是鉴权令牌，不替代同源与访问令牌保护。

兼容性：确认同时省略策略与凭证仍保留旧客户端语义（书架信息按包覆盖；仅大于第 0 章的进度按不早于本机时间合并；缺时间用导入时间）。仅提交两者之一或未知策略返回 400。既有书源/RSS/规则/订阅的冲突规则不变。测试由 `ImportConflictPolicyTest`、`BackupConflictTest` 与 HTTP 备份回归共同约束。

## 浏览器验收

先生成当前 UI（`npm.cmd --prefix product/web run build`，受环境限制时可用已有的 `build:fallback`），再在 `product/` 执行 `./gradlew.bat :app:fatJar --no-daemon --max-workers=1`；最后从仓库根执行 `npm.cmd --prefix product run verify:backup-preview-ui`。需要本机 Chrome/Edge，或通过 `LEGADO_CHROME` / `CHROME_PATH` 指定 Chromium。

脚本固定自建随机回环端口、临时数据库/数据目录与独立浏览器配置，不使用 `LEGADO_BASE_URL`，不连接日常 1234 实例；结束后关闭浏览器和服务并清理临时目录。它逐一核对实例静态文件与 `web/dist` 的 SHA-256，再真实上传 ZIP、点击取消与确认、修改密码和策略、制造预览后进度变化，验证 409 时各模块未部分写入，随后重预览并验证选域恢复。生成的加密凭据仅用于验证默认不勾选，不代表手机导出格式往返验收。

结果、临时服务日志和截图保存在忽略目录 `product/tools/verify/out/backup-preview-ui/`（可用 `LEGADO_VERIFY_OUT` 更改输出父目录）；脚本失败以非零退出码结束。它不会自动构建或重启日常服务，验收前须先完成上述构建。

## 可选真实样本验收

完成当前 fatJar 构建后，在仓库根执行 `npm.cmd --prefix product run verify:backup-real-sample -- '<真实备份 ZIP 的绝对路径>'`。该脚本针对本次已知样本的结构与计数验收，不是任意备份的通用成功判据；备份本身不进入仓库。它自建三个随机回环端口与空临时库，依次检查预览只读、选定原生字段恢复、重复导入、11 个个性化文件字节哈希、原始书源和书架留档的字段/顺序/冲突索引/哈希及重复复用，以及导出到第二空库后六个原生域的再次导出一致性。第三空库独立验证含留档的迁移包恢复。最后关闭服务、删除临时库并复核原包 SHA-256；结果仅记录计数、哈希和检查名称，不保存私人书名、URL 或原始日志。

脚本还检查 `recovery` 清单完整性，将迁移包导入隔离目标库，逐一核对全部留档名称、大小和字节 SHA-256、六域原生 JSON 及重复迁移复用，确认历史源没有被激活。样本的 176 条 RSS 中有 1 条地址为空，须明确报告单项错误，其余 175 条正常导入。个性化文件仅验原样留档，不代表已应用；`all` 导出仍仅含六个原生域。未在手机 App 恢复导出包，未执行真实书源或 WebDAV 请求。输出在忽略目录 `product/tools/verify/out/backup-real-sample/result.json`，失败以非零退出码结束。
