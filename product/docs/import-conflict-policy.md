# 导入冲突策略

`enabled` / `isEnabled` 是本机运行状态，不属于各类定义字段。当前各入口有意保留不同策略；修改入口或冲突语句时，必须同步更新本矩阵和 `ImportConflictPolicyTest`。

| 对象与入口 | 已存在记录冲突时的本机开关策略 | 新记录 |
| --- | --- | --- |
| 普通书源保存（`saveSource`） | 按请求覆盖 `enabled` | 按请求值 |
| 书源备份导入（`importSources`） | 保留本机 `enabled` | 使用备份值 |
| RSS 源导入（`importRssSources`） | 使用导入值覆盖 `enabled` | 使用导入值 |
| 替换规则导入（`importReplaceRules`） | 使用导入值覆盖 `isEnabled` | 使用导入值 |
| 书源订阅保存（`saveSubscription`，按 URL 冲突） | 使用请求值覆盖 `enabled` | 使用请求值 |

备份导入保护本机书源开关，是为了避免恢复另一设备上的完整书源包时批量改变本机策展。RSS、替换规则和订阅入口采用定义整体覆盖语义，开关随导入定义一同更新。普通书源保存是显式保存操作，提交值总是生效。

这是一份行为规范，不代表不同领域必须统一成同一种策略。若产品将来决定改变其中一项，须作为有意识的数据行为变更处理。
