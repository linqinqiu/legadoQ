# 待定功能

这里记录**已经从界面移出、但还没定下来怎么做**的功能。移出不等于删除：数据与接口按现状保留，等需求明确后再决定接回来还是彻底撤掉。

## 书签

**现状**：书签功能没有做好，已从界面移出，当前版本没有任何入口。

- 阅读器的标记条、正文右键菜单、笔记面板都不再提供书签入口。
- 历史数据里 `bookmark=true` 的笔记仍保存在服务端，笔记面板照常列出，只是不再有「书签」徽标和「只看书签」过滤。

**保留了什么**：

- 数据：笔记表里的 `bookmark` 标记与已有记录不动。
- 接口：`/api/notes` 的读写仍接受 `bookmark` 字段（`BookNoteWrite.bookmark`），备份包也按原样带走这部分数据。

**待定要补什么**：

- 边界：书签和划线 / 笔记的区别是什么。书签是否只标位置、不要求选中正文；是否需要独立的书签列表。
- 交互：入口放哪（阅读器工具栏 / 目录 / 笔记面板）、按章还是按页记、能否命名、如何排序与删除。
- 数据：已有的 `bookmark=true` 记录怎么迁移或展示；如果最终不做，再决定是否清数据、撤掉接口字段。
- 一致性：Web 与移动端的入口和命名保持一致。
