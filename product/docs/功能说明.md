# legadoQ 功能说明

legadoQ 把 Legado 书源规则跑在自己的机器上，书架、发现、订阅、朗读与离线缓存都不经过第三方服务。

## 书架

- 书架集中放你收藏的书，可以按分组、阅读状态和最近阅读整理。
- 顶部的「继续阅读」直接接着上次停下的章节往下读。
- 点封面打开阅读器，长按或右键可以调出单本书的管理菜单。
- 可以修改书名、作者和封面，封面支持图片地址并自动缓存到服务端。
- 分组可以新建、改名和删除，书可以在分组之间移动。
- 「换源」会拿书名和作者去其它书源里找同一本书，选中后无缝替换。
- 「离线缓存」会预先下载全书正文，断网时也能读。
- 「标记已读完」和「清除进度」用来把书移到已读完分组或从头开始。

## 书库

- 书库用关键词在全部书源或指定书源里搜书。
- 搜索结果会合并同一本书的多个书源，并标出精准匹配。
- 可以按书名或作者筛选，也可以按书名、字数等排序。
- 搜索历史留在本机，点一下就能重新搜。
- 没有结果时页面给出书架、发现、书源三个快捷入口。

## 书源

- 书源决定书从哪里来、目录怎么切、正文怎么取。
- 支持粘贴 JSON、导入文件或订阅地址来添加书源。
- 「体检」会逐条请求书源，按可用程度给出结论。
- 「调试」会分阶段显示搜索、详情、目录、正文每一步的耗时和结果。
- 书源可以分组、排序、批量启用停用和删除。
- 「分享」把选中的书源打包成一个 JSON 数组导出。
- 书源编辑器的字段提示说明每条规则该填什么。

## 发现

- 发现读取书源自带的推荐页，按分栏列出榜单和分类。
- 可以按书源分组筛选，再从分栏里挑书。
- 列表支持翻页加载更多。

## 订阅

- 订阅页放两类订阅，各占一块，互不影响。
- 书源订阅填一条返回书源 JSON 的直链，每 6 小时同步一次，产物是书源。
- RSS 订阅源填站点或栏目的地址，产物是可读的文章。
- 文章可以阅读、标记已读和打开原文。

## 阅读器

- 点击屏幕中间呼出或收起工具栏，两侧按点击区设置翻页。
- 工具栏可以放切换书源、阅读设置、全屏和朗读，顺序自己定。
- 目录按章节列出字数，点击跳转，当前章会高亮。
- 阅读进度按书保存，关掉再打开会回到上次的位置。
- 选中正文会弹出标记条：划线、笔记、复制、发给 AI。
- 笔记面板集中管理这本书的划线和备注，点击可跳回原文。
- 「纯阅读」隐藏所有控件，「全屏」让页面占满屏幕。
- 「搜索本书」只在已经离线缓存的正文里找关键词。
- 「切换书源」在保留进度的前提下换一个源继续读。

## 朗读

- 朗读支持微软 Edge-TTS、浏览器 Web Speech 和自定义 HTTP 源三种引擎。
- 可以选发音人、调语速和语调。
- 睡眠定时器可以按 15、30、45、60 分钟或读完本章自动停。
- 可以设置读完本章自动连播下一章，并过滤正文里的符号。

## 阅读设置

### 排版

- 字体提供宋体、黑体、楷体、仿宋、圆体、等宽、系统字体和自定义字体名。
- 字号、字间距、行间距、段间距都可以细调。
- 首行缩进按不缩进、1 字、2 字三档。
- 左右边距和版心宽度控制每行多长、正文占多宽。
- 正文对齐可选两端对齐或左对齐。
- 分栏排版可选自适应、单栏和双栏，自适应在宽屏下自动双页分栏。
- 「恢复默认设置」把排版恢复出厂值，保留当前主题和自定义皮肤。

### 颜色与背景

- 内置七套主题：晓白、护眼、夜读、青竹、暮蓝、玫瑰、石墨。
- 自定义皮肤与内置主题在同一张网格里，点哪套用哪套。
- 自定义皮肤在「我的 → 自定义皮肤」里新建，CSS 要自己写完整选择器，例如 .theme-midnight { --canvas: #0f1213; --surface: #171c1e; }。
- 自定义皮肤有两种取值方式：全权自定义只用自己的 CSS，叠在某一档之上则沿用那一档没写到的变量。
- 自定义皮肤只存在这台浏览器里，不上传服务端，也不进备份包。
- 阅读背景可以设纯色、背景图和压暗比例，全部清空则跟随主题。
- 背景图只存在这台浏览器里，不上传服务端。

### 行为

- 翻页方式可选连续滚动或平移分页。
- 平移分页下可选平移过渡、覆盖、淡化或无动画。

### 其它设置

- 简繁转换可以关、简转繁或繁转简，正文和章名一起转。
- 点击区域在正文上拖横竖虚线改分区，改完立刻生效。
- 工具栏决定右上角显示哪些按钮、按什么顺序，至少留一个。
- 本地书目录可以给当前这本换一条目录规则重切，重切会清掉正文缓存并回到第 1 章。
- 内容净化针对当前书籍或书源过滤广告和特定字符。

## 快捷键

### 阅读器

- Page Up、Page Down 或空格向上、向下翻一屏。
- ← 和 → 上一章或下一章，翻页模式下是上一页或下一页。
- Home 和 End 回到本章开头或末尾。
- + 和 - 调整字号，T 换下一套主题。
- D 开关目录，S 开关阅读设置，M 播放或暂停朗读。
- F 全屏，I 纯阅读，Esc 关掉当前抽屉或退出纯阅读。
- Ctrl 或 ⌘ 加滚轮直接调字号。

### 全局

- / 或 Ctrl / ⌘ + F 聚焦当前页的搜索框。
- Alt + ← / → 在一级页面之间循环切换。
- ? 打开快捷键表，L 打开运行日志。
- 数字键 1 到 6 切到对应的那一页。

## 点击区

- 点击区把正文分成若干块，每块点下去做一件事。
- 翻页模式按竖虚线分列，滚动模式按横虚线分段，两张表分开存。
- 每一块可以设为上一页、下一页、呼出工具栏、打开目录、打开设置或不响应。
- 预设提供默认、九宫格、只认两侧和整屏只呼出工具栏。
- 虚线可以拖动改位置，双击删掉，一轴最多五条。

## Cookie 与登录

- 需要登录的书源在书源菜单里打开「登录 / Cookie」。
- 可以用内置浏览器走真实登录，也可以直接粘贴 Cookie。
- 保存后同名 Cookie 覆盖，其它域的凭据保留。
- 登录凭据随备份包导出，导入时需要凭据解密密码。

## 设置页

- 快捷键：打开阅读器与全局的按键表。
- 离线缓存：看哪几本书下了多少章、占多大空间，可以整本清掉。
- 皮肤与配色：打开自定义皮肤。
- 替换净化规则：用正则删掉正文和书名里的广告与杂乱内容。
- TXT 分章规则：决定下一本导入的 TXT 按哪条规则切目录。
- 备份包：导入手机端备份，或把书源、书架、规则导出成一份。
- 运行日志：看服务写了什么，可以导出。
- 服务端口：改 legadoQ 监听的端口，重启后生效。
- 应用名称与图标：改本机安装根里的品牌信息。
- AI 接入：登记 openai-compatible 模型后才能在应用内对话。
