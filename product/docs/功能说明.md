# legadoQ 功能说明

legadoQ 把 Legado 书源规则跑在自己的机器上，书架、发现、订阅、朗读与离线缓存都不经过第三方服务。

## 书架

- 书架集中放你收藏的书，可以按分组、阅读状态和最近阅读整理。
- 顶部的「继续阅读」直接接着上次停下的章节往下读。
- 点封面打开阅读器，长按或右键可以调出单本书的管理菜单。
- 可以修改书名、作者和封面，封面支持图片地址并自动缓存到服务端。
- 分组可以新建、改名和删除，书可以在分组之间移动。
- 「换源」会拿书名和作者去其它书源里找同一本书，选中后无缝替换。
- 「离线缓存」会预先下载全书正文，断网时也能读。
- 「标记已读完」和「清除进度」用来把书移到已读完分组或从头开始。

## 书库

- 书库用关键词在全部书源或指定书源里搜书。
- 搜索结果会合并同一本书的多个书源，并标出精准匹配。
- 可以按书名或作者筛选，也可以按书名、字数等排序。
- 搜索历史留在本机，点一下就能重新搜。
- 没有结果时页面给出书架、发现、书源三个快捷入口。

## 书源

- 书源决定书从哪里来、目录怎么切、正文怎么取。
- 支持粘贴 JSON、导入文件或订阅地址来添加书源。
- 「体检」会逐条请求书源，按可用程度给出结论。
- 「调试」会分阶段显示搜索、详情、目录、正文每一步的耗时和结果。
- 书源可以分组、排序、批量启用停用和删除。
- 「分享」把选中的书源打包成一个 JSON 数组导出。
- 书源编辑器的字段提示说明每条规则该填什么。

## 发现

- 发现读取书源自带的推荐页，按分栏列出榜单和分类。
- 可以按书源分组筛选，再从分栏里挑书。
- 列表支持翻页加载更多。

## 订阅

- 订阅页放两类订阅，各占一块，互不影响。
- 书源订阅填一条返回书源 JSON 的直链，每 6 小时同步一次，产物是书源。
- RSS 订阅源填站点或栏目的地址，产物是可读的文章。
- 文章可以阅读、标记已读和打开原文。

## 阅读器

- 点击屏幕中间呼出或收起工具栏，两侧按点击区设置翻页。
- 工具栏可以放切换书源、阅读设置、全屏和朗读，顺序自己定。
- 目录按章节列出字数，点击跳转，当前章会高亮。
- 阅读进度按书保存，关掉再打开会回到上次的位置。
- 选中正文会弹出标记条：划线、笔记、复制、发给 AI。
- 书签只记位置，不用先选中正文：点工具栏的「书签」记下当前读到的那一段，再点一次取消。
- 笔记面板集中管理这本书的划线、备注和书签，可以按类型筛选，点击跳回原文对应位置。
- 源站改了正文之后，划线与书签会按原文自动找回位置；实在认不出的会标「原文已变，位置可能不准」。
- 「全屏」让阅读器占满屏幕，再按一次退出。
- 「搜索本书」只在已经离线缓存的正文里找关键词，点结果会跳到那一段并把关键词亮出来。
- 「切换书源」在保留进度的前提下换一个源继续读。
- 漫画源一屏一张图、按图翻页；宽屏可以双页对开，顺序可选从左到右或从右到左。
- 漫画读到第几张会记住，关掉再打开回到同一屏；跨章往回翻落在上一章末屏。
- 打开「封面取色」后，阅读时的配色会按这本书的封面自动生成一套（Material 3 动态色）；封面是纯白、纯黑或灰图时不覆盖，保持你选的皮肤。
- 打开「壁纸取色」后，不在读书时按壁纸主色生成同一套配色；两项都关掉就完全听皮肤。

## 朗读

- 朗读支持微软 Edge-TTS、浏览器 Web Speech 和自定义 HTTP 源三种引擎。
- 可以选发音人、调语速和语调。
- 睡眠定时器可以按 15、30、45、60 分钟或读完本章自动停。
- 可以设置读完本章自动连播下一章，并过滤正文里的符号。

## 阅读设置

### 排版

- 字体提供宋体、黑体、楷体、仿宋、圆体、等宽、系统字体和自定义字体名。
- 字号、字间距、行间距、段间距都可以细调。
- 首行缩进按不缩进、1 字、2 字三档。
- 左右边距和版心宽度控制每行多长、正文占多宽。
- 正文对齐可选两端对齐或左对齐。
- 分栏排版可选自适应、单栏和双栏，自适应在宽屏下自动双页分栏。
- 「恢复默认设置」把排版恢复出厂值，保留当前主题、自定义皮肤与预设皮肤的改动。

### 颜色与背景

- 预设的七套主题：晓白、护眼、夜读、青竹、暮蓝、玫瑰、石墨。
- 预设皮肤可以改名、换配色，也可以从列表里隐藏；隐藏的随时能恢复。
- 这七套的名字仍是保留字，自定义皮肤不能占用；对预设皮肤的改动单独保存。
- 自定义皮肤与预设主题在同一张网格里，点哪套用哪套。
- 在「皮肤」浮层里管理：预设皮肤放在「预设皮肤」这一栏编辑，「新建皮肤」用于自定义皮肤；样式要写成 `.theme-<id>` 这种带选择器的规则。
- 自定义皮肤完全独立：没写到的颜色会用默认值补上，不叠加预设配色。
- 预设皮肤的改动、自定义皮肤与隐藏记录都只存在这台电脑的浏览器里，不会上传，也不进备份包；删除前会确认。
- 阅读背景可以设纯色、背景图和压暗比例，全部清空则跟随主题。
- 背景图只存在这台电脑的浏览器里，不会上传。

### 行为

- 翻页方式可选连续滚动或平移分页。
- 平移分页下可选平移过渡、覆盖、淡化或无动画。
- 漫画单图可开关；开了之后还能选双页对开，以及双页从哪一边开始读。

### 其它设置

- 简繁转换可以关、简转繁或繁转简，正文和章名一起转。
- 点击区域在正文上拖横竖虚线改分区，改完立刻生效。
- 工具栏决定右上角显示哪些按钮、按什么顺序，至少留一个。
- 本地书目录可以给当前这本换一条目录规则重切，重切会清掉正文缓存并回到第 1 章。
- 内容净化针对当前书籍或书源过滤广告和特定字符。

## 快捷键

### 阅读器

- Page Up、Page Down 或空格向上、向下翻一屏。
- ← 和 → 上一章或下一章，翻页模式下是上一页或下一页。
- Home 和 End 回到本章开头或末尾。
- + 和 - 调整字号，T 换下一套主题。
- D 开关目录，S 开关阅读设置，M 播放或暂停朗读。
- F 全屏，Esc 关掉当前抽屉。
- Ctrl 或 ⌘ 加滚轮直接调字号。

### 全局

- / 或 Ctrl / ⌘ + F 聚焦当前页的搜索框。
- Alt + ← / → 在一级页面之间循环切换。
- ? 打开快捷键表，L 打开运行日志。
- 数字键 1 到 6 切到对应的那一页。

## 点击区

- 点击区把正文分成若干块，每块点下去做一件事。
- 翻页模式按竖虚线分列，滚动模式按横虚线分段，两张表分开存。
- 每一块可以设为上一页、下一页、呼出工具栏、打开目录、打开设置或不响应。
- 预设提供默认、九宫格、只认两侧和整屏只呼出工具栏。
- 虚线可以拖动改位置，双击删掉，一轴最多五条。

## Cookie 与登录

- 需要登录的书源在书源菜单里打开「登录 / Cookie」。
- 登录推荐用「真浏览器」打开站点完成：登录后会把该站以及跳转途中经过站点的 Cookie 一起收进来。
- 也可以直接粘贴 Cookie；保存后同名 Cookie 覆盖，其它域的凭据保留。
- 登录凭据随备份包导出，导入时需要凭据解密密码。

## 设置页

- 设置按四类分：阅读、外观、数据与凭据、服务与接入。分类只是入口，点开在原编辑器里改。
- 顶部搜索框按标题和说明筛：搜分组名会列出整组，搜具体项只留命中的行。
- 阅读：快捷键、离线缓存、替换净化规则、TXT 分章规则。
- 外观：皮肤、壁纸、应用名称与图标。
- 数据与凭据：Cookie 管理、备份包。
- 服务与接入：服务端口、AI 对话助手、AI 模型连接、AI 工具、AI 外部工具（MCP）、AI 技能、AI 提示词、书源校验、运行日志。
- 「AI 模型连接」里还能按任务选模型：对话、摘要与理解、每条技能各可以指定连接与模型名。
- 「AI 提示词」里每条预设可以只对某个任务生效（对话 / 摘要 / 某条技能）；不勾就是所有任务都注入。
- 也可以反过来配：在「AI 技能」里展开某条技能，直接勾它要用哪几条提示词。
- 「AI 外部工具（MCP）」能接上本机跑着的 MCP 服务：填地址点保存就握手，成功会显示挂上了几个工具；
  这些工具进「AI 工具」的「外部工具」一档，默认关着，模型要先用工具搜索找到再调用。
  服务没起来只让那一组为空，对话照常可用；私网段地址会被拒绝。

## 关于

- 关于页显示版本、开发者、运行位置，可以检查更新、打开更新日志、快捷键与功能说明。
- 「检查更新」对比 GitHub 上带版本号的发布；如果只有持续构建（如 latest），只报发布时间和链接，不判断新旧。
- 「更新日志」看每个版本改了什么，「快捷键」打开按键表。
- 「功能说明」就是这份文档，单独一层打开，不再挤在关于页里。
- 配置了仓库地址时，「项目主页」会出现在动作行里。
