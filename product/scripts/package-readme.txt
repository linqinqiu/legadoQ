青阅 {version} 整合包
=================

这是什么
  一个自带 Java 运行时的「青阅」本机服务。解压后双击 start.bat 即可，
  不需要装 JDK、不需要 Node、不需要联网下载任何东西。
  包里的 runtime\ 是用 jlink 裁出来的精简运行时，只含这个服务用到的模块。

怎么跑
  1. 把 zip 解到一个不含特殊字符的目录（路径里有中文和空格都没问题，但建议短一点）
  2. 双击 start.bat
  3. 脚本会在服务就绪后**自动打开浏览器** http://127.0.0.1:1234/
     （服务冷启动要几十秒，先等一下；没自动打开就手动访问那个地址）
  停止：在那个窗口按 Ctrl+C，或直接关窗口。

一个界面，一个端口
  http://127.0.0.1:1234/        界面（书库、阅读器、订阅、备份……全部功能）
  界面已烤进 jar 里。这台服务不设身份，
  写操作唯一的门是"请求来源的主机和端口必须等于服务自己"，换端口就得放宽这道门。

数据在哪
  默认在包内的 data\ 目录（首次启动会自动建，里面是一个 SQLite 库加封面/正文缓存）。
  这个 zip **不含**任何书源、书架或缓存 —— 程序与数据分开，包才只有几十 MB。
  要把你现有的库带进来，两种办法：
    ① 停服务，把原来那份 data\ 整个覆盖过来（含 legado.sqlite、covers\、local_books\）；
    ② 启动后在「备份」页导入一个青阅备份包（书源 / 书架 / 替换规则 / 阅读进度）。

只绑回环
  服务默认只听 127.0.0.1，局域网连不上。这个服务**没有密码、没有登录**：
  绑定地址就是唯一的门。别把它放到 0.0.0.0 或公网，那等于把整个库交给能连到这台机器的人。

换端口
  三种办法，任选一种：
    ① 双击时带参数：  start.bat 1235
    ② 在包目录里建一个 port.txt，里面只写一个数字（如 1235）
    ③ 编辑 start.bat 里的 LEGADO_PORT
  界面地址跟着端口变。同一台机器上如果已经有一个青阅在跑，先停掉它，
  否则新起的那个会因为端口被占而**直接退出并说明原因**，不会静默失败。

包内容
  {jar}                          服务端（界面已烤在里面）
  runtime\                       jlink 精简运行时
  start.bat                      启动脚本（端口可用参数或 port.txt 指定）
  README.txt                     本文件
  port.txt                       （可选）自己建，里面只写一个端口号
