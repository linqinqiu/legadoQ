# 更新日志

本文件记录「legadoQ」自身的变更。格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，
版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

版本号只有一个来源：`app/build.gradle` 里的 `version`。打 jar 时由 Gradle 写进清单的
`Implementation-Version`，服务端从清单读出来经 `/healthz` 报给界面，所以**构建产物、接口与顶栏显示的
是同一个数**。界面上不写死版本号。

这一份只写**用户能看见的变化**：一条一行，说清多了什么、修了什么。
「为什么这样做、量到了什么、哪条判据盯着它」不写在这里 —— 那些记在 `AGENTS.md`
（部落知识与工作记忆表）和 `docs/sessions/` 里。把工程日志写进更新日志，
使用者就找不到"这版对我有什么变化"了。

版本号用「小更新计数」：三段号 = 档位.小更新序号，每发一次小更新第三段 +1，满 10 进一次级
（0.0.9 之后再发 → 0.1.0）；一版一条，不按天合并。**档位**指前两段：破坏性变更
（接口 / 数据格式 / 需要用户动手迁移）时第二段 +1、第三段清零；没有破坏性变更就只动第三段。
**每次用户可见的变化都要发一版**：哪怕只改一条，也把第三段 +1；同一批多项改动共用一个号。

每个版本条目内的小节按这个**固定顺序**排，同名小节只许出现一次：
`### 新增` → `### 变更` → `### 修复` → `### 移除`。
新增放最前，是因为"这版给我多了什么"比"修了什么"更该先被看到。判据在 `web/test/Changelog.test.ts`，
只盯当前版本那一条（历史条目不回头改）。
每条一句话、不超过一行（约 60 字）；实测数字、根因分析、环境变量名这类工程细节不进这里，
记到 `docs/sessions/`。

## [0.2.1] - 2026-10-30

### 修复

- **凭据管理打开不再卡两秒。** 书源没变动时直接复用上次的统计，不再每次重扫一遍全部书源。
- **重启后第一次打开也快了。** 统计结果会存下来，书源没变就直接用，不再扫一遍全库。

## [0.2.0] - 2026-10-29

### 新增

- **凭据分两层。** 站点发的临时 Cookie 只活到本次重启，不会永久留下，重启后也不再带着作废的中间态。
- **工具可逐项停用。** 展开某一组后能只关掉其中一两条，不必为了避开一个工具牺牲整组。

### 变更

- **凭据超长不再静默失败。** 整条头超过 4096 字符时丢最久没更新的键，凭据管理里列出丢了哪几条。

### 修复

- **退出登录真的会清掉凭据。** 站点用 `Max-Age=0` 撤某条时，本地那条以前还留着，下次照发。

## [0.1.9] - 2026-10-29

### 新增

- **提示词预设。** 把「先给结论、不超过多少字」这类要求存成可开关、可排序的预设，每次对话自动带上。
- **上下文预算。** 历史过长时从最旧的整轮开始丢弃，保留人设与你这次的提问；被丢弃的条数会如实标出。
- **三个 AI 接口。** 提示词预设的增删查进 API 目录，外部程序与界面用同一份契约。

### 变更

- **回答下方标注来源。** 每条回答同时显示用到的技能、提示词条数，以及是否裁过历史。

### 修复

- **提示词排序留得住。** 调整顺序时的两次写入会互相覆盖，改完可能又变回原样。

## [0.1.8] - 2026-10-29

### 新增

- **正文手动刷新。** 目录里可对单章或勾选多章强制回源覆盖缓存；失败直接报错，不拿旧正文顶替。
- **兄弟备份包导入。** 认得 MD3、Max 等项目的 zip 与裸 JSON，书源、书架、规则、RSS 与凭据一并导入。
- **登录界面本地解析。** 带 loginUi 的书源在应用内渲染表单，脚本式 V2 的按钮与状态也能走。
- **三种模型协议。** 连接可选 OpenAI 兼容、OpenAI Responses、Anthropic，预设自动带协议与地址。
- **流式回答与停止。** 回答边生成边显示，可随时停止；思考过程、工具进度与 token 用量一并可见。
- **技能库。** 内置书源排错、阅读助手、书库整理三条，可新建、覆盖、停用与删除（删除进回收站）。
- **拉取模型清单。** 连接表单按协议向服务商取可用模型；不提供清单的协议会直接说明。
- **四个 AI 接口。** 流式对话与技能增删查进 API 目录，外部程序与界面用同一份契约。

### 变更

- **工具参数补全说明。** 55 个内置工具带上完整参数结构，模型调用更少猜错字段。

## [0.1.5] - 2026-10-28

### 新增

- **供应商预设。** 选 OpenAI / DeepSeek / Moonshot / OpenRouter / 硅基流动 / Ollama，地址与常用模型自动填。
- **连接高级选项。** 每个连接可配自定义请求头、超时与思考强度，中转站与自建服务也能接。

### 变更

- **连接可编辑、可选默认。** 密钥留空即不改；多条连接点「设为默认」决定哪条生效。
- **接口响应开启压缩。** 书源清单等大列表的传输量明显变小，加载更快。
- **顶栏图标改用小图。** 不再为 22px 的图标下载 512px 大图，冷启动更省流量。
- **书源登录更顺手。** 「保存并登录」按书源能力走：有登录脚本就执行脚本，只有登录网址就直接打开真浏览器；番茄这类没有登录脚本的源不再报「login is not defined」。
- **所有登录形态都能打开登录页。** 相对路径、登录脚本、jsLib 里的登录跳转都能解析；登录经 passport / OAuth 中转写下的凭据也会一并入库，连登录后跳回书源、中转站标签已经关掉的那一跳（导航历史里还留着）也认得出。
- **真浏览器页签更清爽。** 删去大段说明，抓取 Cookie 后顺带刷新登录态判定。

### 修复

- **壁纸下的大块面板不再做毛玻璃。** 滚动与切页恢复顺滑，顶栏、分区标题与浮层仍保留玻璃质感。
- **书源清单少取一遍。** 启动已经取过的整份书源直接交给书源页，不再重复下载与解析。
- **书源左栏不再是贴边方角色带。** 壁纸下收成内缩圆角卡片，「新建书源」与相邻控件对齐。
- **服务重启后打开真浏览器不再卡住。** 先接上仍然开着的那个窗口，不再重复启动同一个登录档。
- **关掉真浏览器再打开仍是登录态。** 关闭窗口时让浏览器正常退出，Cookie 会写回登录档。
- **书架类分栏不再一律 0 本。** 书源发出的 POST 请求 body 是 JSON 时会自动带上 `Content-Type: application/json`，登录后番茄书架能读出书来。

## [0.0.0] - 2026-10-26

### 新增

- **单机阅读服务重新起步。** 书源规则、搜索、书架、阅读器、离线缓存、朗读、RSS、备份都在一个本机进程里，数据只落在你自己的电脑上。
- **自研分页阅读器。** 纸白底、宋体、可调字号行距与分栏；阅读位置按"章节 + 字符偏移 + 段落锚点"记忆，改设置不跳回第一页。
- **界面资源压缩传输并长期缓存。** 打开过的文件留在浏览器里，重开几乎不再重复下载。
- **设置收纳成单一入口。** 规则、备份、替换净化、阅读记录、诊断、服务、接入与扩展都从「设置」进，原处只留快捷入口。
- **内置 AI 接入网关。** 任意页面右下角的悬浮球带着当前界面上下文提问；模型由你自己登记，没登记就如实说不可用，不拿本地拼凑的答案冒充。

### 变更

- **版本号从 0.0.0 重新计数。** 0.8.6 及以前的日志移到 `docs/archive/CHANGELOG-0.8.6及以前.md`，只作历史留档，不再作为对账依据。
- **构建顺序写死为"先停、再建、再起"。** 跑着的服务加载的是磁盘上那份 fatJar，构建前后各有一道校验，包内前端与磁盘不一致时直接拒绝启动。

### 修复

- **换了版本号或重打过包，启动时不再认错包。** 挑包按当前版本对、判新旧看包里的内容而不是文件时间，避免"跑的还是上一个界面"和"新包被当成旧的"两种误判。
- **门禁不再"本机绿、换台机器红"。** 几处校验此前只在 CI 那种干净环境里误报失败，现在两边结论一致。
- **右下角 AI 球不再压住弹出的窗口与手机阅读底栏。** 弹窗打开时它淡出让位，手机上底栏出现时它抬到底栏之上。
- **打出来的包里没有界面时，首页直说该补哪一步，而不是甩一句服务器错误。**

### 移除

- **插件系统（磁盘 jar 自动装载）。** 装载第三方 jar 等于在本机进程里执行任意代码，而这台服务不设身份；扩展点（工具、钩子、模型协议、连接策略）照旧全部保留。
- **设置页的「界面偏好」分区。** 两个开关写下的值没有任何地方读取，描述的浮动窗口也早已不存在 —— 说谎的控件不如没有。
